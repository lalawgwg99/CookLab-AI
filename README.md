## 🤖 AI 社群貼文助手

**不需任何設定，開啟即用。** 智慧文案只使用 Cloudflare Workers AI 的純文字 8B 基本模型，不接圖片生成模型。免費額度不足或服務忙碌時自動切回內容更完整、支援中英文的瀏覽器本機產生器。訪客不需 API 金鑰或信用卡。

### 支援風格
| 風格 | 適用平台 |
|------|---------|
| 🤖 AI 智慧自動匹配（推薦）| AI 自動判定最佳平台體裁 |
| ☁️ 文青質感 | IG 日常、咖啡探店、生活紀錄 |
| 💬 Threads 觀點 | 爆款短評、思考討論 |
| 📢 LINE 社群團購 | 群組推播、團購優惠 |
| 🛍️ 商品促銷導購 | 電商促銷、引爆購買慾望 |
| ✨ 小紅書種草 | 探店提案、質感好物推薦 |
| 💡 職人專業 | 設計師心得、工作經驗分享 |
| 🫠 幽默社畜 | 週五下班、生活吐嘈日記 |

### 保護機制
- **防連點鎖定**：生成中立即禁止重複點擊
- **重複請求攔截**：內容未修改時自動拒絕重送，節省 Token
- **3 秒冷卻保護**：每次完成後鎖定 3 秒，防止手滑浪費

## 🔒 隱私說明

- 一般文字工具在瀏覽器端完成，不上傳文字內容
- AI 貼文助手會把送出的文字交由 Cloudflare Workers AI 處理；本站不儲存該內容
- AI 免費額度設有單一使用者與全站每日上限，無法使用時自動切回本機產生器
- 最近使用、收藏紀錄僅存於本機 localStorage

---

## 🌐 介面說明

- 支援**繁體中文**與**英文**，依瀏覽器語言自動選擇，右上角可手動切換
- 支援**深色模式**，自動跟隨系統主題，右上角可手動切換
