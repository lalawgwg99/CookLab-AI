# 字研所 TextLab

一個為繁體中文使用者設計的免費日常文字工具箱。

## 第一批工具

- 683 個特殊符號、19 種分類、搜尋與一鍵複製
- 811 個 Emoji、13 種分類、搜尋與最近使用
- 顏文字搜尋與收藏
- Unicode 特殊字體轉換
- IG／Threads 排版與換行工具
- 暱稱產生器
- 空白文字產生與複製

所有文字處理皆在瀏覽器端完成，不需登入。

介面支援繁體中文與英文，會依瀏覽器語言自動選擇，也能透過右上角切換。社群排版提供可見的格式預覽與範本；空白文字工具提供三種 Unicode 字元、平台情境說明與貼上測試。

特殊符號工具另支援最近使用、收藏、熱門符號、Unicode 編碼資訊，以及可分享的分類連結。

## 開發

```bash
npm install
npm run dev
```
