## 🤖 AI 社群貼文助手

**不需任何設定，開啟即用。** 系統已內建 AI 連線，由 [OpenRouter](https://openrouter.ai) 提供支援，使用 NVIDIA Nemotron 3 Super 120B 免費模型。

### 支援風格
| 風格 | 適用平台 |
|------|---------|
| 🤖 AI 智慧自動匹配（推薦）| AI 自動判定最佳平台體裁 |
| ☁️ 文青質感 | IG 日常、咖啡探店、生活紀錄 |
| 💬 Threads 觀點 | 爆款短評、思考討論 |
| 📢 LINE 社群團購 | 群組推播、團購優惠 |
| 🛍️ 商品促銷導購 | 電商促銷、引爆購買慾望 |
| ✨ 小紅書種草 | 探店提案、質感好物推薦 |
| 💡 職人專業 | 設計師心得、工作經驗分享 |
| 🫠 幽默社畜 | 週五下班、生活吐嘈日記 |

### 保護機制
- **防連點鎖定**：生成中立即禁止重複點擊
- **重複請求攔截**：內容未修改時自動拒絕重送，節省 Token
- **3 秒冷卻保護**：每次完成後鎖定 3 秒，防止手滑浪費

## 🔒 隱私說明

- 所有文字工具在瀏覽器端完成，不上傳任何資料
- AI 貼文助手會將輸入內容送至 OpenRouter API 進行生成
- 最近使用、收藏紀錄僅存於本機 localStorage

## 🌐 介面說明

- 支援**繁體中文**與**英文**，依瀏覽器語言自動選擇，右上角可手動切換
- 支援**深色模式**，自動跟隨系統主題，右上角可手動切換
